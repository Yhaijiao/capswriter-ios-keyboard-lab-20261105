# v0.4.3：首次显示、混拼与自动语音上屏

- 三页内容以 Auto Layout 绑定横向分页视口，页面高度始终等于可见高度，禁止纵向滚动。语音状态行固定高度，避免首次尺寸协商后麦克风被裁切。新增从较高初始容器缩回常规高度的真实 UIKit 回归。
- 公共离线词典补充音节边界索引，按音节解析全拼、简拼和两者混用。覆盖 wm→我们、nihm→你好吗、womxianz→我们现在，并保留分段选字和剩余拼音。
- 停止录音后等待电脑最终识别，结果自动插入当前输入框，恢复麦克风待机，不再需要点击“插入文字”。隐藏期间到达的结果保留至键盘重新显示；同一任务只插入一次。空结果和错误可直接重试。

这一版尚未传输录音中的音频分块，不提供逐字实时上屏。使用频率学习、客户端自动更新和 AWS 迁移仍为后续工作。对齐与长按加速删除保持已有行为。

测试：Swift 词典与最终结果交付检查、窗口中的首次布局及尺寸变化、真实扩展启用与输入/滑动/长按删除。手机上的真实麦克风与宿主布局需安装后验收。
