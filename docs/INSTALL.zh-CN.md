# 明早安装与验收

## 先区分三种结果

1. **源码已写好**：可阅读与修改，尚不能代表能编译。
2. **IPA 构建成功**：存在实际 iPhone arm64 可执行文件和键盘扩展，仍需本地签名。
3. **真机验收成功**：你手机上实际安装、启用、输入、刷新均通过。

只有检查报告明确记录完成的项目才算通过。不要把模拟器截图当成真机验证。

## 电脑准备

1. 只从 https://sideloadly.io/ 下载 Windows 版。
2. 官方提示若需 Apple 驱动 / iTunes / iCloud，按官方下载来源安装。此步骤会修改系统与 AppData，属于项目目录以外的安装操作，由机主执行。
3. USB 连接并解锁 iPhone 15 Pro Max，点击“信任此电脑”，输入手机密码。
4. 打开 Sideloadly，确认设备列表出现自己的 iPhone。

不要把 Apple 密码或验证码写入聊天、仓库或构建环境。需要 Apple 登录时，在本地工具中自行输入。

## 安装实验版

1. 从构建产物中取出 `CapsWriterLab-0.4.1-unsigned.ipa`。
2. 拖入 Sideloadly，选择手机，输入自己的免费 Apple 账号。
3. 开启自动刷新选项。首次先用 USB，Wi-Fi 配对成功后再改无线刷新。
4. 保留主 App 和键盘 `.appex` 扩展。若工具询问是否移除扩展，选择保留。
5. 点击 Start，在机主本地完成 Apple 登录和二次验证。
6. 记录实际签名时的 Bundle ID；后续刷新保持相同账号和 ID。重签工具可能自动修改 ID，原始工程 ID 为：
   - 主 App：`org.capswriterlab.keyboard`
   - 键盘：`org.capswriterlab.keyboard.extension`
7. 按手机提示启用“设置 → 隐私与安全性 → 开发者模式”，重启后确认。
8. 必要时在“设置 → 通用 → VPN 与设备管理”中信任自己的开发者身份。

若签名或安装报错，把错误完整记录在本地验收表，不先删除手机原有 App 或安装证书服务。

## 启用与基础输入

1. 打开 CapsWriter Lab，看见说明页和测试区。
2. 设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → CapsWriter Lab。
3. **先不开“允许完全访问”**，在备忘录新建普通笔记。
4. 长按地球键，选择 CapsWriter Lab。
5. 左滑到 EN，输入 hello，确认文字进入备忘录。麦克风用于真实语音，需要按主 App 说明开启会话。
6. 点击删除、空格、@ 和 Return；应逐项改变当前文本，Return 只换行。
7. 左滑一次到 EN，输入 `hello`；点击 Shift 测试大小写，点击 123 测试数字标点。
8. 再左滑到拼音，连续输入 `wom`，检查“我们”“我妈”等候选；输入 `nihaom`，检查“你好吗”。候选栏横向滚动不会切换模式。中间先不选字，才能测试整段拼音组合。
9. 再左滑，回到语音测试页；右滑也能反向循环。顶部波形 / EN / 拼可直接点选。
10. 长按地球键，确认能切回系统键盘。
11. 切换 App、关闭再打开键盘，重复基础输入。

拼音支持全拼组合、v 代替 ü、末音节补全和点击候选上屏。整段最长 64 个字母，最多 40 项候选；选择短词组后保留剩余拼音。未选拼音时删除先删拼音；长按删除会加速。空格、Return 或离开拼音页会把待选拼音按首选候选分段上屏。简拼、语境模型和个人词频学习仍待后续开发。

真实语音：连接电脑桥接，允许完全访问，在主 App 授予麦克风权限并开启 10/30/60 分钟会话，再回键盘点击麦克风开始、停止和插入。单段最长 5 分钟。详见 UPGRADE-0.4.zh-CN.md 中的语音限制；该文档描述 v0.4.0 的基础升级，v0.4.1 新增 UI 和拼音修正。

## 免费刷新验证

1. 首次安装成功后，记录时间、账号标识、实际 Bundle ID 和工具显示的到期日（记录中不要写密码）。
2. 在 Sideloadly 中主动执行一次刷新，确认仍可打开主 App 并使用键盘；这只验证手动重签。
3. 按官方 FAQ 开启 Wi-Fi 同步，保持电脑后台刷新组件运行，手机与电脑同网。必要时点亮手机。
4. 隔天查看后台刷新记录与到期时间是否推进，再测试键盘。
5. 到第 6～7 天复查自动刷新实际发生过。只有工具日志和新的有效期均有证据，才能标为自动刷新已验证。

免费账号还有 App 数量和 App ID 数量限制。扩展会使用额外 App ID；遇到配额限制时不要连续改变 Bundle ID 重试。

## 可选电脑热词实验

按 `SHARED-HOTWORDS.zh-CN.md` 启动只读桥接；主 App 填入 LAN 地址、配对码并检查版本。键盘联网需“允许完全访问”，首次本地网络访问也需手机授权。

主 App 点击“复制配对配置，交给键盘”；5 分钟内回到键盘 → 电脑 → 粘贴配对配置 → 检查版本 / 纠正测试短句 → 插入已预览的结果。

这是用户主动的剪贴板交接，不依赖 App Groups，不会自动读取输入框上下文。配对码短暂存在本地剪贴板，使用后可复制普通文字覆盖。
