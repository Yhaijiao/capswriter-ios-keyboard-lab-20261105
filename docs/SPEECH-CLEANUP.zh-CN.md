# 语音清理：删语气词和重复词

电脑桥接在识别结果上屏前，用固定规则删掉语气词和口吃式的重复词。不接大模型、不联网、不花钱，耗时可以忽略（一千句长文不到 0.1 秒）。

处理顺序：识别结果 → **语音清理** → 热词替换 → 标点处理 → 替换规则。标点仍由电脑 CapsWriter 原有流程负责，清理只会顺手去掉被删语气词留下的多余逗号。

## 默认会做什么

| 规则 | 例子 |
| --- | --- |
| 任何位置的「嗯」「呃」 | 「我想，嗯，去吃饭」→「我想，去吃饭」 |
| 单独成一小句、后面是逗号的「啊 / 额 / 那个 / 这个 / 就是 / 就是说」 | 「那个，我想问一下」→「我想问一下」 |
| 口吃的单字（我、你、他、这、那、就……） | 「我我我想去」→「我想去」 |
| 常见连接词连说两遍 | 「然后然后我们」→「然后我们」 |
| 3 到 8 个字的短语连说两遍 | 「我今天我今天去了」→「我今天去了」 |

## 不会动什么

- 正常用法：「我要那个」「那个人是谁」「好啊」「金额」。
- 叠词：「看看」「谢谢」「妈妈」「研究研究」「哈哈哈」「对对对」「一步一步」。
- 数字、英文单词、网址。
- 整句话只有语气词（只说了一声「嗯」）时原样保留，不会变成空白。

## 开关和词表

桥接第一次启动时会在 `bridge` 文件夹里生成 `speech-cleanup.txt`，用记事本打开就能改：

- `enabled = off` 关闭全部清理。
- 每一行是一张词表，词之间用空格隔开，可以增删。
- 保存后下一句话就生效，不用重启桥接。删掉这个文件再重启桥接会恢复默认。

启动参数：`--cleanup-file <路径>` 换一个位置放规则文件；`--no-cleanup` 完全不加载这个功能。

## 已知取舍

规则偏保守，宁可漏删也不误删：没有逗号隔开的「那个我想问」不会删「那个」；两个字的词只有在词表里才会去重。句子里故意提到「嗯」这个字时也会被删掉，介意的话把它从 `fillers_anywhere` 里拿掉。边说边上屏的草稿不做清理，只清理最终结果。
