# v0.4.1：拼音组合与键盘操作

基于 v0.4.0 的真机反馈修正：wom 只有单一词组、长拼音缺乏组合、中英文键盘上下错位，以及删除键不能长按。

- 使用有上限的词组分词与组合，末音节可未输完。wom 同时提供我们、我妈、我没等候选；nihaom 提供你好吗等组合。
- 长全拼可组合整句，也提供较短词组供分段选择。选择前段后，后续拼音保留；最多 64 个字母、40 项候选。
- 中英文共用四行布局，按键大小与纵向位置一致。语音页 Return 与文字页底部对齐；空闲时不显示操作提示和演示按钮。输入拼音时，候选占用同一高度的顶部栏。
- 删除键短按删一个字符，按住 0.4 秒开始连续删除，随后逐步加速；松手、拖出按键、切换页面或收起键盘即停止。

当前词组排序使用公开词频、常见词种子和读音优先级。wm 简拼、全拼与简拼混输、语境模型、个人词频学习、展开候选网格及手机内客户端更新仍待后续开发。参考图中的混合简拼整句效果不计为本版已实现。

语音仍复用 v0.4 电脑桥接：单段 5 分钟，主 App 会话可选 10/30/60 分钟。AWS 未部署；电脑与手机仍需在同一私人局域网。

验收时检查：wom 多候选、nihaom 选字且无残留、womendouyouyigejia 长句与分段选择、慢拖动时键帽对齐、短按删除一个字符、长按连删和松手即停。编译、自动测试和真机结果分别记录，不能以安装成功代替功能验收。
